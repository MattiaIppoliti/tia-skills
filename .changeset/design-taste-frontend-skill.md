Vendor Leonxlnx's `design-taste-frontend` skill (tasteskill v2) into `engineering/`.

It art-directs public web pages instead of letting the agent produce the average landing page: an inventory of what only this client has, three directions dealt by `scripts/draw.mjs` from a library distilled from 247 gallery sites, a build from the chosen sheet, then a gate of `scripts/lint.mjs` on the source and `scripts/inspect.mjs` in a real browser at 1440, 768 and 390, and up to three rounds of screenshot critique and fixes. The scripts need Node 22+ and a local Chrome, Edge or Chromium, and install nothing.

Model-invoked, wired into `plugin.json`, both `README.md`s, `docs/engineering/design-taste-frontend.md`, and `ask-mattia`'s Standalone section next to `/apple-design` and `/web-design-guidelines`. Only the main skill came over from [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill), not its style variants. The rules, scripts and library are unchanged; the only edits are 13 em-dash rewrites in prose and code comments.
